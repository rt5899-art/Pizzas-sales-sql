# Pizzas-sales-sql
What it is: A SQL-based pizza sales data analysis project. The repo contains 4 CSV datasets that form a relational database schema:
FileContentsorders.csvOrder-level data (order IDs, dates/times)order_details.csvLine items per order (quantity, pizza ID)pizzas.csvPizza variants (size, price)pizza_types.csvPizza categories and ingredients
It also includes a workflow JSON file (likely a data pipeline or n8n/similar automation) and a pizza sale flyer PDF.
What you can do with this data:

Total revenue, orders, and average order value
Best and worst-selling pizzas by quantity and revenue
Sales trends by hour, day, or month
Category breakdowns (classic, veggie, chicken, etc.)
Size preference analysis
